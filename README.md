# SuruhAja – Gojek‑style Service Platform

## Overview
SuruhAja is a lightweight PHP/MySQL application that mimics core functionalities of on‑demand services such as Gojek or Astro. It supports three user roles:
- **Customer** – can browse services, place orders, pay via Midtrans Snap, view order history, and rate drivers.
- **Driver** – can accept orders, update status through the lifecycle (`Proses → Diterima → Dalam Perjalanan → Selesai`), or cancel (`Batal`).
- **Admin** – full visibility of all orders, can change any order’s status, view analytics, and manage services.

Key features implemented so far:
- Role‑based authentication and CSRF protection.
- Order creation with price, address, and map integration.
- Payment handling with a `payment_status` column and Midtrans webhook.
- Real‑time driver dashboard status polling (AJAX).
- Customer order history with driver name and average rating.
- Driver profile showing vehicle info and average rating.
- Admin dashboard and order management UI.
- Email notifications on status changes (customer and admin actions).
- Dockerfile for container deployment.
- GitHub Actions CI workflow for PHP linting.

## Setup
1. **Clone the repository**
   ```bash
   git clone https://github.com/notsalter/SuruhAja.git
   cd SuruhAja
   ```
2. **Create the database** (adjust credentials in `config.php`):
   ```sql
   CREATE DATABASE suruhaja;
   USE suruhaja;
   SOURCE migrations/*.sql;   -- run all migration files
   ```
3. **Install dependencies** (Midtrans SDK via Composer if not already present):
   ```bash
   composer install
   ```
4. **Configure environment** – edit `config.php` with your DB credentials and Midtrans server key.
5. **Run locally** – with Apache/PHP or via Docker:
   ```bash
   docker build -t suruhaja .
   docker run -p 80:80 suruhaja
   ```
6. **Set up Midtrans webhook** – point to `order_payment_callback.php` to receive payment status updates.
